# Seattle Airbnb Market Analysis | Power BI

## Project Overview
This project analyses Seattle Airbnb listings to understand accommodation pricing, availability, and neighbourhood-level market trends.

Using Power BI, I cleaned and transformed data, created relationships between datasets, developed DAX measures, and built visualisations to explore business questions.

## Dataset
The project uses three related datasets:
- **Listings:** 3,818 Airbnb properties
- **Calendar:** Daily availability and pricing information
- **Reviews:** Guest review information

## Tools and Techniques
- Power BI Desktop
- Power Query for data cleaning and transformation
- Data modelling and table relationships
- DAX measures and calculations
- Interactive dashboards and data visualisation

## Data Preparation
- Converted pricing fields into numeric values for analysis
- Examined missing values in property and review-related columns
- Connected listings, calendar, and reviews using listing identifiers
- Prepared the data model for neighbourhood and availability analysis

## Key Analysis
- Total number of Airbnb listings
- Average daily listing price
- Availability and estimated occupancy indicators
- Price differences across neighbourhoods
- Review activity and property characteristics

## Findings
- Pricing and availability varied across Seattle neighbourhoods.
- Queen Anne showed relatively high prices and lower availability in the project analysis.
- North College Park was identified as an area with relatively low availability.

## Business Value
This dashboard demonstrates how accommodation data can help identify pricing patterns, compare neighbourhood performance, and support market research.
